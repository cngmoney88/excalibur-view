The Mac version — and the first public release since 0.6.1, so this carries
0.6.2 and 0.6.3 with it.

## It runs on a Mac

One download, signed and notarized by Apple, running natively on Apple Silicon
and Intel. Not a viewer, not a browser tab, not a cut-down edition: the same
program as the Windows one, built from the same source. Open the disk image,
drag Excalibur View into Applications, and open it from there.

Bluebeam stopped making Revu for Mac in 2019 and ended it in 2023. As far as we
know this is the only full desktop takeoff and markup program that runs
natively on both Windows and Mac.

Macs keep themselves up to date the same way Windows machines do. An office
server holds both builds and hands each seat its own, so a shop with Macs and
PCs in it is still one server and one set of drawings.

Needs macOS 11 Big Sur or later.

## Excalibur View Sealed

For offices that are not allowed to let a program reach the internet at all.
A Sealed copy talks to its own office server and nothing else — every outward
connection is refused, not merely switched off, and no setting inside the
program can turn it back on. Administrators set it through Group Policy on
Windows or a managed preference on a Mac, and policy outranks the licence:
a computer sealed by its administrator stays sealed.

Sealed offices keep an append-only record of who did what, exportable as CSV
for an auditor.

## A shop can take somebody's access away

Until now the only way to deal with somebody leaving was to change the join
code, which does nothing to the account they already have or the session they
are already in.

Sign Out now signs a seat out for real. The session is destroyed on the
server, so the token stops working the moment it is pressed rather than thirty
days later.

The server can also change a person's role and remove them outright. Both take
effect on the next thing that seat asks it, not the next time it signs in, so
there is no window where a removed account still works, and removing somebody
takes their keys with them. These two are on the server before they are on a
screen: today an administrator makes the request to the server directly, and
the People screen that puts it in front of you is the next thing being built.

What somebody made stays behind them. A markup carries its author's name and a
set carries who uploaded it, written down as text rather than pointing at an
account, so a takeoff does not lose its history because somebody left the
company.

Every one of these — adding a person, changing a role, removing one, signing a
seat out, revoking a key, exporting a takeoff — goes into the record the
server keeps, with who did it and when. So does a sign-in refused for an
address nobody has, which is the one an administrator most wants to see.

## Licences that renew themselves

Buying three more seats means waiting on a file to be signed and emailed over.
A server can now fetch its own renewal instead, on the same half-hourly trip
it already makes to look for updates, so more seats or another year are in
place inside the hour with nobody sending anybody anything.

Nothing about that trip decides a licence is good. What comes back is checked
against the keys built into the server, the same way an update is, and then
checked against the licence already held: one that gives fewer seats, ends
sooner, or belongs to somebody else is thrown away and the old one kept. It is
not an account — no password, no session, nothing to reset — and the server
sends nothing about itself, not a seat count, not a company name.

This ships switched off, and switches on the day we publish the first renewal.
A sealed office never asks at all, by design: its licences arrive as files, by
hand, the way a sealed office wants everything to arrive.

## Also in this release

- Claude works in the free app, not only in Office (0.6.2).
- The website's download links and checksums come off the release itself, so
  they are never out of date (0.6.2).
- Licence rules finished: seats, expiry and what happens when a licence runs
  out are all settled the same way everywhere (0.6.2).
- Markup text no longer sits over the sheet by default (0.6.3).
- Staying signed in to Studio, with the signed-in account shown in the top bar.
- Updates now carry more than one platform in a single release, and a signature
  over one platform's build can never be passed off as another's.
- Studio's project list keeps itself current. It used to be asked for once, at
  sign-in, so a drawing set somebody else put on the server — or that FabWire
  pushed across from a bid — did not appear until the program was quit and
  started again.
